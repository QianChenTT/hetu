The security service: a small Windows service under its own account, the only writer of hetu's security state. It hands out a one-time code for a requested change and writes the change only with a Windows Hello signature over that code and change, under the key it enrolled. Only an elevated program can enroll a key. The helper hetu ships makes the key itself and checks it, at first install or after a lost key. Not built yet, it will be C# on .NET Framework 4.8 and its packaging is tracked in #75
