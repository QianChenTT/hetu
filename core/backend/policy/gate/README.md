The gate, a core module in main that holds the gate policy job. It decides each call with power on the newest grants snapshot the plugins manager pushed: each plugin's grants as items, each with its switch and whether its first use asks. Windows are judged on `core/api`'s fixed window grants, never on the grants snapshot

`gate.ts` holds the logic: `decide` at the raw stage and the canonical one, asking at an item's first use, `canRead` and `canList` for events and listings and `stateChanged` for each new grants snapshot, with each grant's scopes compiled once per grants snapshot through `compileScopes`. `core/backend/wire.ts` makes it and `core/backend/modules/modules.ts` hands it each grants snapshot. A `stateChanged` that throws marks the gate failed until the next one goes through. Its tests are in `core/test/modules/gate`
