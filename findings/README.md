# Findings

Security findings in hetu, published as they are found.

Each writeup covers:

- **Summary:** what goes wrong and who can do it
- **Exploit:** the steps that make it happen, run against a tagged commit
- **Root cause:** why the code allowed it
- **Fix:** the change that closes it
- **Regression test:** a test that fails before the fix and passes after
- **Detection:** what the event log shows when someone tries it
- **Found by:** which build check flagged it, or missed by all

The `baseline` tag marks the code before the build sprint guardrails
