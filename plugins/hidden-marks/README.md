Hidden marks: markdown's markers hidden and its text styled while you type, `**bold**` drawn bold with the asterisks hidden. The text itself never changes and Ctrl+/ always shows the real text

The code is `core/frontend/mount/hidden-marks.ts`, compiled into the editor page from the install. This folder is its install plugin: the manifest with a `page` entry and the module bundled on its own, which the install list hashes. The plugin list shows it and switches it, and the editor applies hidden marks only while it is ready. There is no loader path for in-page code. It is to move behind the editor bridge as a plugin (#98), not built yet
