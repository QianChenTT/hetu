The capabilities slot's install plugin. Its host half classifies a plugin-folder plugin from 0 to 4, picks the items that ask at their first use and writes the lines the trusted window shows under the core's words. It answers from what the loader hands it and makes no calls

- **a grant's class:** `ui.*` but `ui.keys`, `ui.edit` and `ui.read`, `storage`, `events.subscribe` and `plugin.call` itself 0. `ui.keys`, `ui.read`, `luoshu.read` and `luoshu.list` 1. `luoshu.write` 2, or 4 when its first path part holds a wildcard. `history` 2. `ui.edit` 2 on any scope, since each edit waits in the editor for the human's save. `net.fetch` 3, or 4 with `*`. `exec`, `guard.hook` and `log.read` 4
- **a plugin's class:** the highest of its grants and the grants it reaches through `plugin.call`, either way round, which the loader follows. A subscription gives the plugin that hears none of the speaker's grants, so it never raises the listener's class
- **the pair rule:** a plugin is 4 when a read can reach it and it can reach network: it reads or a plugin upstream of it reads, and it holds network or a plugin downstream of it holds network, since together they could send notes out. Data moves along `plugin.call` both ways and along a subscription to another plugin's topics one way, from the plugin that owns the topic to the plugin that hears it, followed in turn through any mix of the two. With `plugin.call` alone that is reading and network anywhere in what the plugin reaches. Reading here counts `luoshu.read`, `luoshu.list`, `ui.read`, `ui.keys`, `luoshu.write` and `history` read
- **first use:** the items whose own class is 4, and for a pair the items that close it: the plugin's network items, or with none the `plugin.call` items that bring the network in, and for a plugin that reads nothing itself the subscriptions a read moves in through
- **the screen:** the class and its name, what the plugin reaches through `plugin.call` and, for one with network, the plugins that read and are connected to it that way. Past `plugin.call`, one with network names the plugins that read and can reach it through events and one that reads names the plugins with network it can reach through events. A last line names the programs in its `exec` items that run other programs or code

`src/capabilities.ts` holds the logic and `src/host.ts` is what the loader imports: the plugin and the `capabilities` role
