One package per plugin with one manifest and one identity. Its entries say where each half runs: `worker` in a hidden renderer and `frames` in a window. Install plugins may also have `host` in the main process and `page` in a window. The manifest names `requires` and `provides`, install plugins also `guards` and `node`. The host-level plugins built so far are gate, capabilities, storage, luoshu, history and exec. The watchdog, leases, net and http are designed and not built. The event log is the core's own. Hidden marks runs in-page, compiled into the editor page from the install. CodeMirror is the editor window's own, no plugin. Search and the layout run sandboxed today. Git, the file explorer, artifacts and MCP are designed to and aren't built
