The gate, an install plugin whose host half holds the gate slot. It decides each call with power on the newest StateView the loader pushed: each plugin's grants as items, each with its switch and whether its first use asks. Windows are judged on `core/api`'s fixed window grants, never on the StateView

`src/gate.ts` holds the logic: `decide` at the raw stage and the canonical one, asking at an item's first use, `canRead` and `canList` for events and listings and `stateChanged` for each new StateView, with each grant's scopes compiled once per StateView through `compileScopes`. `src/host.ts` is what the loader imports: the plugin as its default export and the `gate` role
