One package per plugin with one manifest and one identity. Its entries say where each half runs: `worker` in a hidden renderer and `frames` in a window. A core plugin, loaded only from the install, may also have `host`, which runs in a utility process of its own and never in main. The manifest names `requires`, `provides`, `views` and a `theme`, core plugins also `guards` and `node`

Three plugins live here. `mcp-http-handler/` is the core plugin MCP clients are to come in through, a host half in its utility process with two doors: HTTP on `127.0.0.1:4747` and a local pipe that the shim `hetu.exe --mcp-stdio` relays an agent's stdin and stdout over. Each request meets the door's checks and goes on as one `mcp.handle` call with the client's label as `onBehalf`. The HTTP door answers every token 401, since the build that ships issues none. A client on the pipe joins once the human confirms it. Both doors are open only while an `mcp` plugin is there and none is in this repo. Leases and net are designed and not built

The gate, the grant risk classifier, flood control, the heartbeat, recording, the security view, storage, the luoshu, history, exec and the lock are no plugins. They are core modules in `core/backend`, bundled into `main.js`, each with its own switch. No plugin runs in main. CodeMirror is the editor window's own, no plugin

`layout/` is hetu's own layout and `hidden-marks/` hides markdown's markers while you type, both built on `@hetu/sdk` and tested on its fake core and its fake drawer. The install carries both as first-party copies, which run sandboxed from the plugin folder as workers in the first-party hidden renderer. Hidden marks reaches the editor only through the editor bridge, so no plugin's code runs in the editor page. Search and the file explorer are no longer part of hetu: a data folder from an older build that holds either as a first-party copy keeps it in the plugin folder refused with `signer` and runs no worker for it. A plugin may declare `views` drawn as trees or frames and a `theme` of token values in its manifest. Git, artifacts and MCP are designed to run sandboxed and aren't built
